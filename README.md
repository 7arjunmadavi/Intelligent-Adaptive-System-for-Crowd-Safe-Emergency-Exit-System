Intelligent Adaptive System for Crowd-Safe Emergency Exit

Overview
An intelligent and adaptive emergency evacuation system designed to enhance crowd safety and improve evacuation efficiency during fire emergencies. The system integrates ESP32-based fire detection, sensor-based hazard monitoring, adaptive LED floor navigation, YOLO-based real-time crowd detection, voice-guided evacuation instructions, and a web dashboard for live crowd monitoring and evacuation assistance.

Problem Statement
Traditional emergency evacuation systems provide static exit guidance without considering real-time fire hazards or crowd conditions. This can lead to congestion, unsafe routes, and inefficient evacuation during emergencies.

Key Features
- Real-Time Fire Detection: ESP32-based flame detection and hazard monitoring.
- AI-Based Crowd Detection: YOLO-powered real-time people detection and crowd estimation.
- Adaptive LED Navigation: Dynamic LED floor indicators guiding occupants toward safer exits.
- Voice-Based Guidance: Audio instructions to assist occupants during evacuation.
- Live Monitoring Dashboard: Web dashboard for real-time crowd monitoring and evacuation assistance.
- Intelligent Evacuation Assistance: Integration of crowd information and environmental conditions for safer evacuation guidance.

System Architecture
1. Flame sensors detect fire hazards in the evacuation environment.
2. ESP32 processes sensor inputs and communicates hazard information.
3. YOLO detects people and estimates crowd density from camera footage.
4. The system identifies safer evacuation routes based on hazard and crowd information.
5. LED floor navigation provides visual evacuation guidance.
6. Voice instructions assist occupants during evacuation.
7. A web dashboard displays live crowd information and evacuation status.
